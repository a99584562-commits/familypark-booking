# Фемили парк — календарь бронирования беседок (демо)

Интерактивное демо для загородного парка с 23 беседками: живая «шахматка» вместо Excel-таблицы,
которую администраторы ведут параллельно с Битрикс24.

**Что внутри**

- Шахматка на месяц (даты × беседки) — 1:1 со структурой клиентской таблицы, но со статусами, поиском и статистикой
- Таймлайн дня по часам: окна между бронями, час перезаезда, линия «сейчас»
- Карточка брони: расчёт цены по тарифу дня (будни / выходные / праздники), доп. услуги, проверка пересечений и вместимости
- Реестр броней с фильтрами, тарифы 2026, выпускные пакеты
- Страница интеграции с Битрикс24: маппинг полей, живой журнал синхронизации, дорожная карта

Данные условные, имена вымышленные. Состояние хранится в localStorage (кнопка «Сбросить демо-данные» в сайдбаре).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5216
npm run build    # dist/
```

Стек: Vite + React + TypeScript + Tailwind v4 + zustand. Деплой — GitHub Pages через Actions (push в `main`).
